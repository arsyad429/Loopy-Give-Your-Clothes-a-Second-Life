# Tes UI pemeriksaan pakaian

[ClothingDetectorScreenTest.kt](ClothingDetectorScreenTest.kt) menguji pemilih kamera dan galeri, pratinjau, jenis pakaian, kualitas foto, serta tombol yang dikunci saat analisis. [CheckResultScreenTest.kt](CheckResultScreenTest.kt) menguji tampilan hasil dan syarat untuk lanjut ke pickup.

Tes memakai state dan callback uji untuk memeriksa UI. Verifikasi unggahan dan Groq dilakukan melalui pengujian API atau demo perangkat yang terhubung ke backend. [Kode pemeriksaan](../../../../../../../main/java/id/ac/loopy/feature/clothingcheck/README.md)
