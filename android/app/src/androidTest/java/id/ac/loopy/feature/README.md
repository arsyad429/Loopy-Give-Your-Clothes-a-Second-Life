# Tes Compose per fitur

- [HomeScreenTest.kt](HomeScreenTest.kt) memeriksa aksi di Beranda, avatar yang langsung membuka profil, dan retry ketika data gagal dimuat.
- [ProfileNavigationTest.kt](ProfileNavigationTest.kt) menelusuri kembali dari profil lalu membuka Pengajuan untuk admin dan Donasiku untuk donatur. Tes juga memastikan aksi keluar yang tersisa dari profil lama tidak dipanggil, sementara tombol keluar yang ditekan saat profil aktif berfungsi.
- [UserTabNavigationTest.kt](UserTabNavigationTest.kt) memeriksa tab Beranda dari Donasiku dan Rewards.

Folder [clothingcheck](clothingcheck/README.md) dan [pickup](pickup/README.md) memuat tes UI untuk alur pemeriksaan dan formulir. [Panduan instrumentasi](../../../../../README.md)
