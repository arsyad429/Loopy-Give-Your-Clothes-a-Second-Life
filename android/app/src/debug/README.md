# Override manifest debug

[AndroidManifest.xml](AndroidManifest.xml) mengizinkan cleartext untuk build debug sehingga emulator dan perangkat yang memakai `adb reverse` dapat mengakses backend HTTP lokal. URL ditetapkan saat build melalui `LOOPY_API_BASE_URL`. [Build Android](../../../README.md) · [Manifest utama](../main/README.md)
