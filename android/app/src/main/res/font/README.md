# Font S05

Plus Jakarta Sans dari Google Fonts (ofl/plusjakartasans), SIL Open Font License pada OFL.md.
Lima TTF statis diekspor dari variable font pada weight 400/500/600/700/800. Bobot 800 dipakai untuk saldo poin melalui LoopyScreen. Sumber variable font: [Google Fonts Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans).
Dipakai ClothingDetectorScreen: heading 26/32, title 18/24, body 14/21, label 14/20, caption 12/18.
Tidak membutuhkan unduhan font saat runtime.
