# res

Resource Android untuk ikon, font, nilai aplikasi, dan konfigurasi FileProvider.

## Isi file dan perannya

| File atau folder | Kegunaan |
| --- | --- |
| [`values/`](values/README.md) | Resource nilai yang dirujuk oleh manifest atau aplikasi Android. |
| [`xml/`](xml/README.md) | Konfigurasi jalur FileProvider untuk berbagi URI foto dengan aplikasi kamera. |
| [`drawable`](drawable/README.md) | VectorDrawable dan lisensi ikon kamera serta hasil pemeriksaan. |
| [`font`](font/README.md) | Font Plus Jakarta Sans dan lisensi distribusinya. |
