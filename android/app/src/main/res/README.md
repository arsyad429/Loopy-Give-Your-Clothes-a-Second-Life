# Resource Android

| Folder | Resource |
| --- | --- |
| [drawable](drawable/README.md) | Vektor untuk panah, kamera, serta status pemeriksaan. |
| [drawable-xxxhdpi](drawable-xxxhdpi/README.md) | PNG dari SVG Figma untuk kartu dan navigasi. |
| [font](font/README.md) | Font lokal Plus Jakarta Sans. |
| [values](values/README.md) | Nama aplikasi dan tema awal dari manifest. |
| [xml](xml/README.md) | Jalur foto sementara yang boleh dibagikan oleh FileProvider. |

Task `prepareMainResources` menyalin resource dan menyaring Markdown sebelum kompilasi. Sunting sumber di folder ini. [Konfigurasi Gradle](../../../build.gradle.kts)
