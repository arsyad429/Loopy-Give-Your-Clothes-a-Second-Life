# Aset Figma untuk donasi dan reward

SVG asli diekspor dari file Figma Loopy `ZDndr4gOItY7elDq9w7YA3`, node S04 `2:87`, S09 `2:94`, dan S10 `2:95`, pada 23 November 2026. Ikon leaf, image, gift, house, package, circle-check, calendar-days, map-pin, dan shirt merupakan komponen Lucide berlisensi ISC; lihat `res/drawable/LICENSE-lucide.md`.

PNG pada `res/drawable-xxxhdpi/` dirender dari SVG ini dengan resvg pada skala 4x. Geometri sumber dipertahankan. Ukuran tampilan ditentukan sesuai slot Figma di `CompletionComponents.kt`: ikon navigasi 22dp, reward 32dp, riwayat reward 44dp, dan hero shirt 48dp. Figma memakai bentuk ikon yang sama pada ukuran berbeda.
