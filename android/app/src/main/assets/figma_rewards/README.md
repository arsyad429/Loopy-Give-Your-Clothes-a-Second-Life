# Sumber ikon Figma

SVG diekspor dari file Figma Loopy `ZDndr4gOItY7elDq9w7YA3`, node S04 `2:87`, S09 `2:94`, dan S10 `2:95`, pada 23 November 2026. Aset Lucide mencakup leaf, image, gift, house, package, circle-check, calendar-days, map-pin, dan shirt. [Lisensi Lucide](../../res/drawable/LICENSE-lucide.md)

PNG di [drawable-xxxhdpi](../../res/drawable-xxxhdpi/README.md) dirender dengan resvg pada skala 4x. [CompletionComponents.kt](../../java/id/ac/loopy/ui/components/CompletionComponents.kt) menentukan ukuran tampilan, termasuk 22 dp untuk navigasi dan 48 dp untuk hero shirt. Perbarui sumber SVG dan PNG terkait jika ikon berubah.
