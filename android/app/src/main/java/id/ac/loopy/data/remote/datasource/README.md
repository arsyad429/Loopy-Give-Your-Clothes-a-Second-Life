# Kerangka remote data source

Kelima file `*RemoteDataSource.kt` menyisakan rancangan lapisan remote untuk autentikasi, pemeriksaan, donasi, admin, dan rewards. Jika mengubah fitur yang berjalan, mulai dari [interface Retrofit](../api/README.md) dan [implementasi repository](../../repository/README.md). Integrasi aktif memanggil interface Retrofit dari repository.
