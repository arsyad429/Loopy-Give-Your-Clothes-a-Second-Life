# Payload API Android

[AuthDto.kt](AuthDto.kt) mencakup login, sesi, profil, dan challenge OTP. [ClothingCheckDto.kt](ClothingCheckDto.kt) membawa hasil AI. [DonationDto.kt](DonationDto.kt) membawa pengajuan, riwayat, dan cursor. [AdminDto.kt](AdminDto.kt) memuat payload admin. [RewardDto.kt](RewardDto.kt) memuat saldo, katalog dan penukaran.

Cocokkan nama field, nullability, dan perubahan JSON dengan [kontrak server](../../../../../../../../../../../docs/api-contract.md) serta [mapper](../../mapper/README.md).
