# loopy

Direktori loopy mengelompokkan source/config Loopy. README subfolder menjelaskan implementasi spesifik.

## Isi file dan perannya

| File/folder | Peran dan isi yang diharapkan |
| --- | --- |
| `LoopyApplication.kt` | Application pemilik AppContainer sepanjang proses. |
| `MainActivity.kt` | setContent/edge-to-edge, ViewModel factory, lifecycle-aware collection dan Logcat lifecycle debug. |
| `core/` | Baca README di subfolder core untuk peran file dan TODO. |
| `data/` | Baca README di subfolder data untuk peran file dan TODO. |
| `di/` | Baca README di subfolder di untuk peran file dan TODO. |
| `domain/` | Baca README di subfolder domain untuk peran file dan TODO. |
| `feature/` | Baca README di subfolder feature untuk peran file dan TODO. |
| `ui/` | Baca README di subfolder ui untuk peran file dan TODO. |
