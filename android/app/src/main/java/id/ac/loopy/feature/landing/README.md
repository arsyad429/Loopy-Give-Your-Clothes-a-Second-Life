# S01 Landing

[LandingScreen.kt](LandingScreen.kt) memperkenalkan Loopy dan menyediakan aksi Masuk dan Daftar. [LoopyApp.kt](../../ui/LoopyApp.kt) menetapkan S01 sebagai tujuan awal dan menghubungkan tindakan tersebut ke S02 atau S03.

`LandingViewModel.kt` dan `LandingUiState.kt` menyisakan kerangka state untuk konten yang mungkin perlu dimuat kelak. Konten saat ini dirender langsung dari composable. [Peta layar](../../../../../../../../../../docs/screen-map.md)
