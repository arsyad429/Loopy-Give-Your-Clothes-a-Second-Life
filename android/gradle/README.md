# gradle

Direktori gradle mengelompokkan source/config Loopy. README subfolder menjelaskan implementasi spesifik.

## Isi file dan perannya

| File/folder | Peran dan isi yang diharapkan |
| --- | --- |
| `libs.versions.toml` | Version catalog Android terpusat: Kotlin, Compose, Room, DataStore, Retrofit, lifecycle, Navigation, tests. |
| `wrapper/` | Baca README di subfolder wrapper untuk peran file dan TODO. |
