# Desain Loopy

[Loopy — Mobile UI · 13 Screens.fig](Loopy%20%E2%80%94%20Mobile%20UI%20%C2%B7%2013%20Screens.fig) adalah arsip desain asli untuk layar MVP. Buka file di Figma dan gunakan [peta layar](../docs/screen-map.md) untuk menemukan node, rute aplikasi, dan kebutuhan layar tambahan. [Referensi desain yang diekspor](../docs/reference/README.md)

Aset yang dipakai aplikasi berada di [assets Android](../android/app/src/main/assets/README.md) dan [resource Android](../android/app/src/main/res/README.md). Cocokkan perubahan visual dengan node terkait dan uji pada ukuran layar perangkat.
